# Кастомные ленты vc.ru

Интерактивный прототип с разделом «Мои ленты» в сайдбаре после рейтинга.
На мобильных устройствах ленты доступны в верхней полосе с горизонтальной прокруткой.
Выбранные ленты, их порядок и иконки сохраняются в браузере. Публикации
случайно выбираются из сохранённого набора. Переходы на прод отключены.

## Локальный запуск

Откройте `index.html` или запустите `python3 -m http.server 8080` и перейдите
на http://localhost:8080/.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите
**Deploy from a branch**, ветку **main** и папку **/ (root)**, затем **Save**.
Проект статический, сборка не нужна. Файл `.nojekyll` отключает обработку Jekyll.

Ресурсы интерфейса и публикаций находятся в `vcru/`, аватарки — в `feed-assets/`.
Это демонстрационный прототип, не официальный сайт vc.ru.

## Дизайн-система

Оформление сверено со скиллом `osnova-design-system` (снимок 23.10.2026).
Токены темы вынесены в `design-tokens.css`, стили прототипа — в `custom-feeds.css`.
Управляющие SVG взяты из каталога скилла. Выбор иконки ленты остаётся контурным,
как согласовано для этого прототипа.
